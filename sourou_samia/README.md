# SOUROU SAMIA — Coopérative Céréalière du Sourou

Site vitrine en français pour la Coopérative Céréalière du Sourou, au Burkina Faso.
Développé en **HTML5, CSS3 et JavaScript**, sans framework ni CDN. Il fonctionne
en local ou sur un réseau intranet.

## Ouvrir le site

Ouvrir `index.html` dans un navigateur récent, ou démarrer un serveur local :

```bash
python3 -m http.server 8000 --bind 0.0.0.0
